- Minimum Operations to Sort a String, Minecraft edition. Today's daily problem, number thirty eight sixty three.
- One operation picks any piece of the string, except the whole thing, and sorts it.
- What's the fewest operations to sort the whole string? Or minus one, if it can't be done.
- The direct idea is a search. Sort every possible piece, then every piece again, level by level.
- A string of length n has about n squared pieces, and every sort makes a new string.
- Even our four letters need more than a hundred sorts to explore every string.
- With a hundred thousand letters, that search would never finish.
- Here's the trick. The answer is never more than three. We only need the smallest and the largest letter.
- If the smallest is already first, sort everything after it. If the largest is already last, sort everything before it. One operation.
- Our string is d b c a. Let's run the checks, one by one.
- Is it already sorted? No. Is it just two letters? No, so it can be done.
- Is a, the smallest, first? No. Is d, the largest, last? No. So one operation is not enough.
- Does a appear before the last spot? No, it's only at the end. Does d appear after the first spot? No.
- Both letters are stuck at the wrong ends, so the answer is three. Let's watch it happen.
- Sort d b c into b c d. Then sort c d a into a c d. Then sort b a c into a b c. Sorted!
- Advancement made. Three operations sort d b c a.
- We only find the smallest and the largest, and scan a few times. The time is linear.
- And the extra memory is constant. No search at all.
- A few checks, and the answer is zero, one, two, three, or minus one.
- Sometimes the best algorithm is a proof. Think before you search.
