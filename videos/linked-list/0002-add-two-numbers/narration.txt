subtitles:
- Add Two Numbers, Minecraft edition. LeetCode problem number two, the classic linked list warm up.
- We get two chains of blocks. Each block holds one digit, and points to the next block.
- The digits are stored in reverse order, so the ones digit comes first.
- So this chain is nine hundred forty two, and this one is nine thousand four hundred sixty five.
- Return their sum as a new chain, in the same reversed order.
- The tempting shortcut is to turn both chains into integers and just add them.
- But a chain can hold a hundred digits. That overflows any normal integer type.
- Here's the trick. Reverse order is exactly how we add by hand, starting from the ones place.
- Add each column, write down the last digit, and carry the rest to the next column.
- So we walk both chains together, one block at a time, holding a carry.
- First column. Two plus five is seven, and there's no carry.
- Next, four plus six is ten. We place a zero, and carry the one.
- Then nine plus four, plus the carry, is fourteen. Place a four, carry one.
- The first chain has run out, so it counts as zero. Nine plus one is ten. Zero, carry one.
- Both chains are finished, but we still hold a carry. So we add one final block.
- Advancement made. Seven, zero, four, zero, one. That's ten thousand four hundred seven.
- Each block is visited once, so the time is linear in the longer chain.
- And the new chain takes the same amount of extra space.
- One loop, one carry, and a dummy head to keep the code clean.
- Reverse order turns linked lists into grade school addition.
