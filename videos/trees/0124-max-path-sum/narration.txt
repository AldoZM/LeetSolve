- Binary Tree Maximum Path Sum. LeetCode one twenty four, a classic hard.
- A path is any chain of connected nodes, each used at most once. Find the path with the largest sum.
- The path doesn't have to pass through the root. Here, the best one is fifteen, twenty, seven. That's forty two.
- Trying every pair of start and end nodes would be far too slow.
- Instead, look at the top of a path, its highest node. The path takes that node, plus its best branch on the left, plus its best branch on the right.
- But a path can only bend once. So when a node reports up to its parent, it can only offer one branch.
- And if a branch is negative, we simply drop it, and use zero instead.
- Let's run it bottom up. We start with the leaves on the left.
- Minus four is negative, so its parent will drop it. Two offers a gain of two.
- At nine, the best path through it is nine plus two, eleven. It offers eleven to its parent.
- On the right, fifteen and seven offer themselves.
- At twenty, the path fifteen, twenty, seven sums to forty two. That's the new best. It offers twenty plus fifteen, thirty five.
- At the root, minus ten plus eleven plus thirty five is only thirty six. So the answer stays forty two.
- Each node is visited once, so the time is linear.
- The recursion goes as deep as the tree, so the space is the height.
- Return one branch up, but score both branches at every node.
- Bend once at the top, and keep the best.
