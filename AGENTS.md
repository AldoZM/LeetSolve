# LeetSolve

Lee `GUIA.md` completo antes de crear o modificar cualquier video. Ahí están el estilo aprobado, el formato, la estructura de carpetas, el flujo de trabajo y los problemas conocidos. Para hacer un video nuevo, sigue `INSTRUCCIONES_IA.md` paso a paso. `BITACORA.md` resume qué se hizo en cada sesión; agrega una entrada al terminar.
